full_num:all voxels' counting ; Both voxel and all voxel utilize an ```unordered_map``` to assign a unique key to each voxel. The key is generated by multiplying the x, y, and z coordinates by large prime numbers and summing them. Along with this key, a corresponding key index (acquired by incrementing ```num++```) is stored. This approach creates a hash table that contains all the required voxels in ```share_data->voxels```.
设置32位的nbv_view_cases用来代表三十二个视角点的选取情况，依次通过将1LL左移k位的循环方法来分别处理初始选取1到32个视角点now_view_cases的情况，chosen_views为选取的视角i，通过auto& key : *share_data->voxels[i]调取第i个视角下的所有的体素的个数，然后用新的observed_voxel 遍历所有的体素，最后在二元向量distrubution中的第i-1个（从0开始）存储now_num_visible / full_num这个比值，并且添加这个视角到全部的nbv_view_cases中。接下来在还在这个循环内设置打分系统，初始化向量score，32个视角的score都为零，遍历views.size,如果视角还未被选择，score等于该视角内新增加的体素量，设置best_views_id以及best_score进行比较，遍历选出最优的view_id，now_view_case |= (1LL << best_view_id) 通过这个添加最佳的view_id到now_view_case进行循环直到now_num_visible == full_num，continue。
nbv_j.txt表示chosen_view的个数为j时，新增第i个视角时now_num_visible / full_num的值，也就是增加的观测到的voxel的量，view_cases.txt 表示从第1个视点开始通过计算最佳视点直到ful_num满足的视角增加过程。
Use a 32-bit `nbv_view_cases` to represent the selection state of 32 viewpoints. By iterating over `k` and left-shifting `1LL` by `k` (i.e., `1LL << k`), we handle the scenario of initially selecting from 1 to 32 viewpoints for `now_view_cases`. The variable `chosen_views` represents the selected viewpoint `i`. For each `auto& key : *share_data->voxels[i]`, we retrieve the number of voxels under viewpoint `i`. Then, we use a new `observed_voxel` to iterate over all these voxels. Finally, we store the ratio `now_num_visible / full_num` in the `(i-1)`-th entry (starting from 0) of the 2D vector `distribution`, and add this viewpoint to the overall `nbv_view_cases`.

Next, within this loop, we set up a scoring system by initializing a `score` vector, where all 32 viewpoint scores are initially zero. We iterate over `views.size()`, and if a viewpoint has not been selected yet, its score equals the number of newly added voxels for that viewpoint. We define `best_views_id` and `best_score` for comparison, iterate to find the best `view_id`, and then use:``` now_view_case |= (1LL << best_view_id)```;to add the best view_id to now_view_case. This continues until now_num_visible == full_num, then proceeds (continue)
The file `nbv_j.txt` indicates the value of `now_num_visible / full_num`—i.e., the number of newly observed voxels—when the chosen_view count is `j` and a new viewpoint `i` is added. The file `view_cases.txt` shows the incremental process of adding viewpoints one by one (starting from the first viewpoint) by computing the best new viewpoint until `full_num` is reached.








































## Datagenerator

The `Datagenerator` directory contains programs that generate training data. This module can operate in multiple modes to create different types of data outputs:

- **Voxel Data Generation**
- **Point Cloud Data Generation**
- **Coverage Calculation**: Computes coverage metrics to evaluate data completeness.

### Requirements
To use the programs in this repository, ensure that the following libraries are installed:

- OpenCV 4.4.0
- PCL (Point Cloud Library) 1.9.1
- Eigen 3.3.9
- OctoMap 1.9.6
- Gurobi 9.1.1 (Note: Gurobi is only free for academic use)

The code can be compiled using **Visual Studio 2019** with support for **C++ 14** and is intended to run on **Windows 10**. For use on other systems, please verify compatibility, particularly with file reading/writing functions and multithreading features, as adjustments may be needed.

## GVPN
This directory contains my neural network implementations. The model.py file stores several neural network models, and running this file directly allows you to test the output results of the models. The dataset.py script is designed to preprocess the training data. You can train the neural networks by running train.py.
